Security & data flow

Access is a responsibility.

These principles govern our integration design. The public website itself collects no OAuth tokens and includes no analytics, advertising, or account database.

01 / MINIMIZE

Ephemeral Processing

Transient API payloads should exist only for the requested processing task. Any integration that needs persistent output must disclose the data and retention period before collection.

02 / RESPECT

Zero Credential Selling

We do not sell credentials, OAuth tokens, or personal information. Never send passwords, API keys, or access tokens to our support inbox.

03 / PROTECT

End-to-End TLS

HTTPS is required for supported user-to-service and service-to-API connections. TLS protects data in transit; it does not mean providers cannot process authorized requests.
