What the kit is designed to do

Explicit column mapping; exact, case-sensitive identifiers by default; optional key normalization; exact decimal comparisons; no monetary percent when currencies are missing, invalid or different; separate JSON and spreadsheet-neutralized CSV review reports. Processing stays in the app's tab, and original files are not rewritten.

Included guides explain how to review export completeness, key stability, variants, duplicate groups and source evidence before any downstream update.

Limits: product-only UTF-8 comma-separated CSV, 1 MiB / 5,000 data records / 50 columns per file. Requires an appropriate stable key. This is a generic snapshot comparison, not live monitoring, product-identity inference, platform import certification, inventory truth or a guarantee of business results. Multi-row/variant exports may need different rules.
