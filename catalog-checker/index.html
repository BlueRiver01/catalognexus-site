What it checks

Small rules.
Useful questions.

  • Missing SKU, title, price, currency or stock.
  • Possible duplicate SKUs, compared after trimming; case-sensitive.
  • Nonnegative decimal prices and whole-number stock.
  • Three-letter uppercase currency format.
  • Leading/trailing whitespace and formula prefixes in mapped fields.
  • Optional GTIN check digits and HTTP(S) image URL syntax.

What it cannot tell you

A flag needs context.

A clean result does not prove that an import is safe. The checker cannot verify actual stock, correct prices, GTIN ownership, image availability, or marketplace approval.

It does not merge, correct, or import anything. Spreadsheet formula prefixes are warnings, not a complete spreadsheet security check. An image URL is never fetched.

Currency formatting is checked; currency code registration is not. Multi-row platform exports may need a different schema and business rules.

Before you begin

A few practical answers.

Will you receive my file?

No. The free checker reads it locally in your browser and sends no file data to CatalogNexus. The email link opens your email app; only send column names and a record count initially. The hosting provider processes normal web request metadata.

Can I use a Shopify, WooCommerce or supplier export?

You can explicitly map appropriate columns, but this is a generic field check, not an import validator for those platforms. For example, Shopify can use multiple rows per product. Blank titles on additional rows may be expected and flagged here. Do not treat these flags as instructions to change a live store. Shopify’s CSV documentation ↗

Does the free version change my data?

No. It reads the selected file and creates a separate list of findings. The JSON download contains record numbers and finding descriptions, not copies of your product values. The original file is not changed.

What is the paid service adding?

Review of the agreed schema and rules, the separate HTML and JSON diagnostic, source fingerprint, and an explanation of findings and limits. The free tool is an initial screen. The current pilot does not include cleanup, data enrichment, imports, store access or ongoing monitoring.
